# বাংলা Text-to-Speech API (বিনামূল্যে)

Microsoft-এর নিউরাল বাংলা ভয়েস দিয়ে লেখা থেকে MP3 অডিও তৈরি করে। কোনো Google/Gemini API key লাগে না।

## ধাপ ১: GitHub-এ আপলোড
1. GitHub-এ নতুন Repository খুলুন (নাম: `bangla-tts-api`)
2. **Add file → Upload files** চাপুন
3. এই ৩টি ফাইল আপলোড করুন: `main.py`, `requirements.txt`, `render.yaml`
4. **Commit changes** চাপুন

## ধাপ ২: Render-এ চালু করুন (ফ্রি)
1. https://render.com এ GitHub দিয়ে সাইন আপ করুন
2. **New → Blueprint** চাপুন
3. আপনার `bangla-tts-api` repository বেছে নিন
4. **Apply** চাপুন এবং ৩-৫ মিনিট অপেক্ষা করুন
5. শেষ হলে উপরে আপনার লিংক দেখাবে, যেমন: `https://bangla-tts-api-xxxx.onrender.com`

## ধাপ ৩: আপনার API Key নিন
Render-এ আপনার সার্ভিস খুলুন → **Environment** → `API_KEY`-এর পাশে **Show** চাপুন। ওই লম্বা কোডটিই আপনার key। এটি গোপন রাখুন।

## ব্যবহার

ব্রাউজারে পরীক্ষা করুন:
```
https://আপনার-লিংক.onrender.com/tts?text=আমি বাংলায় কথা বলি&key=আপনার_KEY
```

| বিষয় | কী লিখবেন |
|---|---|
| লেখা | `text=...` |
| ভয়েস | `voice=bn-BD-NabanitaNeural` (নারী), `bn-BD-PradeepNeural` (পুরুষ) |
| গতি | `rate=10` (দ্রুত), `rate=-10` (ধীর) |
| পিচ | `pitch=5` (চিকন), `pitch=-5` (ভারী) |
| ভয়েস তালিকা | `/voices` |

উত্তরে MP3 ফাইল আসবে। বড় লেখা হলে POST ব্যবহার করুন: `POST /tts`, Body: `{"text": "...", "voice": "bn-BD-NabanitaNeural"}`

## অ্যাপ বানানোর AI-কে যা বলবেন (কপি করে পেস্ট করুন)

```
আমার অ্যাপে এখন Gemini TTS দিয়ে অডিও তৈরি হয়। সেটি বদলে নিচের API ব্যবহার করো:
GET https://আপনার-লিংক.onrender.com/tts?text=<লেখা URL-encode করে>&voice=bn-BD-NabanitaNeural&key=আপনার_KEY
উত্তরে audio/mpeg (MP3) আসবে, সেটি প্লে করো।
লেখা ৩০০০ অক্ষরের বেশি হলে বাক্য ধরে টুকরা করে একটি একটি করে পাঠাও ও ক্রমানুসারে চালাও।
যদি এই API ব্যর্থ হয় (৫xx বা টাইমআউট), তখন আগের Gemini TTS দিয়ে চেষ্টা করো।
প্রথম রিকোয়েস্টে ৬০ সেকেন্ড পর্যন্ত টাইমআউট রাখো।
```

## জেনে রাখুন (সীমাবদ্ধতা)
- **ঘুমিয়ে পড়া:** ফ্রি সার্ভার ১৫ মিনিট ব্যবহার না হলে ঘুমায়। ঘুম থেকে উঠতে প্রথম কলে ৩০-৬০ সেকেন্ড লাগতে পারে।
- **লিমিট:** প্রতি IP-তে মিনিটে ৩০টি অনুরোধ, একবারে ৩০০০ অক্ষর। Render-এর Environment-এ `RATE_LIMIT_PER_MIN` ও `MAX_CHARS` বদলে নিতে পারেন।
- **অনানুষ্ঠানিক সেবা:** এটি Microsoft Edge-এর Read Aloud সেবা ব্যবহার করে। তারা যেকোনো সময় বদলাতে বা বন্ধ করতে পারে। তাই অ্যাপে Gemini-কে ফলব্যাক রাখুন।
- Render-এর ফ্রি প্ল্যানের শর্ত মাঝে মাঝে বদলায়, সাইনআপের সময় দেখে নিন।
